# CV Generator Bot

Цей Telegram-бот аналізує IT-вакансії та автоматично генерує адаптовані CV (резюме) і Cover Letter на основі профілю кандидата за допомогою штучного інтелекту Gemini.

## 🚀 Як це працює
1. **Аналіз вакансії**: Користувач відправляє текст вакансії в бот. Бот аналізує, наскільки кандидат підходить під цю роль, шукає "red flags", необхідні навички та оцінює збіг (match).
2. **Генерація документів**: Після аналізу з'являються кнопки "Згенерувати CV" та "Згенерувати Cover Letter". Бот використовує інформацію з вакансії, щоб персоналізувати документи під вимоги роботодавця.
3. **Експорт у PDF**: Усі згенеровані документи (CV та Cover Letter) конвертуються з Markdown у професійний PDF-формат та надсилаються назад користувачеві у вигляді файлів.

## 📂 Структура проєкту

- `.env` — файл з секретними ключами (Telegram Token, Gemini API Key). **Не додавати в Git!**
- `master_profile.md` — файл з описом профілю кандидата (досвід роботи, навички, контакти, мови). Саме цей файл використовується Gemini для генерації документів.
- `src/index.js` — точка входу, яка запускає бота.
- `src/bot/bot.js` — налаштування бота на базі бібліотеки `grammy` (реєстрація сесій та команд).
- `src/bot/handlers/` — обробники подій:
  - `message.js` — обробляє текст вакансії, зберігає його в сесію і генерує початковий аналіз.
  - `callback.js` — обробляє натискання кнопок, викликає генерацію CV/Cover Letter, створює PDF та надсилає їх у чат.
- `src/ai/client.js` — клієнт для взаємодії з Google Gemini API.
- `src/ai/prompts.js` — промпти (інструкції) для ШІ (як проводити аналіз, як писати CV, як писати Cover Letter).
- `src/utils/fileSystem.js` — допоміжні функції для роботи з файловою системою (читання профілю).
- `tests/` — модульні тести для перевірки коду.

## ⚙️ Встановлення та налаштування

1. Клонувати репозиторій.
2. Встановити залежності:
   ```bash
   npm install
   ```
3. Створити файл `.env` у кореневій папці та додати наступні ключі:
   ```
   TELEGRAM_TOKEN=твій_токен_від_botfather
   GEMINI_API_KEY=твій_ключ_gemini
   MODEL_NAME=gemini-3.6-flash
   ```
4. Відредагувати `master_profile.md`, щоб додати свій реальний досвід, навички та контакти.

## 🏃 Запуск бота

Щоб запустити бота, використовуйте команду:
```bash
npm start
```
*Якщо виникають проблеми з PDF-генератором (puppeteer), можливо, знадобиться виконати команду `npm rebuild puppeteer` або `npx puppeteer browsers install chrome`.*

## 🧪 Тестування

Для запуску тестів використовуйте команду:
```bash
npm test
```

## 🛠️ Як оновлювати/перероблювати бота в майбутньому

- **Змінити стиль резюме**: Редагуйте файл `src/ai/prompts.js` (функція `getCvPrompt`).
- **Змінити стиль Cover Letter**: Редагуйте файл `src/ai/prompts.js` (функція `getCoverLetterPrompt`).
- **Оновити свої навички**: Просто оновіть файл `master_profile.md`, ніяких змін у коді робити не потрібно.
- **Додати нові кнопки або функціонал**: Додайте нову логіку у `src/bot/handlers/callback.js` та оновіть клавіатуру у `src/bot/handlers/message.js`.
